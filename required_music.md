# 필요한 음악 — required_music (2026-11-04)

아직 비어 있는 음악 상자 **26개**와 바로 복사해 쓰는 프롬프트예요. 위에서부터 중요해요.
프롬프트는 **공통 꼬리까지 다 붙어 있어요** — 코드 블록을 통째로 복사해서 AI 음악 도구에 넣으면 돼요.

만든 음악은 **파일 이름 = 상자 이름**으로 이 폴더에 넣고 `tools/add-music.sh` (예: `music-source/sam.wav`, `music-source/scene.meetCape.wav`).
같은 곡을 두 상자에 쓰고 싶으면 파일을 복사해서 두 이름으로 넣어요.
전체 방향·규격·권리는 [README.md](README.md). 비어 있는지 확인은 브라우저 콘솔 `checkMusic()`.
