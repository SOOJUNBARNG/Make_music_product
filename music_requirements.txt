# ============================================================
# 音楽要件ファイル (ACE-Step 1.5 / GPU 版)
#
# 元にした仕様: ゲーム側の docs/music-brief.md (2026-10-27, 第1部 + 第2部 = 56 상자)
#   - プロンプトは music-brief.md「7. AI 음악 도구용 프롬프트」をそのまま使用
#   - そこに無い상자は、music-brief.md「3. 상자 목록」の場面説明から作成
#   - 長さは「4. 파일 규격」: 기본 음악 1분 30초~3분 / 이벤트 음악 30초~1분
#
# 手元から:   infra/gcp.sh run          (GCP の GPU VM 上で全曲を生成)
# VM 上で:    python make_music.py music_requirements.txt
#
# 上から順に全曲を生成して output_dir に <상자>.wav (48kHz ステレオ) で保存します。
# すでにファイルがある曲はスキップするので、途中で止まっても再実行で続きから再開できます。
#
# 書式 (INI 形式):
#   [상자 이름]           ← 出力ファイル名になる (例: [trial.storm] → trial.storm.wav)
#   priority = 1|2|3      ← 1: 꼭 필요한 곡 / 2: 있으면 좋은 곡 / 3: 나머지
#   duration = 秒数       ← 10〜598 秒 (ACE-Step は 1 回で最大 10 分まで作れる)
#   prompt   = 英語の説明  ← 曲の説明 (style と合わせて 512 文字以内)
#   gain_db  = -6         ← (任意) 音量。会話シーン (scene.*) は台詞を邪魔しないよう小さめに
#   copy_of  = 別の상자   ← (任意) 生成せず別の曲をコピー
#   seed     = 整数       ← (任意) 曲ごとの乱数シード
#   bpm / keyscale / timesignature ← (任意) 指定しなければ ACE-Step が自動で決める
#                            例: bpm = 70 / keyscale = D major / timesignature = 4
# 行頭 # はコメント。prompt は次の行をインデントすると複数行で書けます。
# ============================================================
