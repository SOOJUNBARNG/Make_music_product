# ============================================================
# 音楽要件ファイル (README_music.md の 45 個の「상자」から作成)
#
#   .venv/bin/python make_music.py music_requirements.txt
#
# を実行すると、上から順に全曲を生成して output_dir に <상자>.wav で保存します。
# すでにファイルがある曲はスキップするので、途中で止めても再実行で続きから再開できます。
#
# 書式 (INI 形式):
#   [상자 이름]          ← 出力ファイル名になる (例: [trial.storm] → trial.storm.wav)
#   priority = 1|2|3     ← README の ①必須 / ②あると良い / ③残り
#   duration = 秒数      ← 最大 28 秒推奨。28 + ループ用クロスフェード 2 秒 = 30 秒を 1 回で生成できる
#                          (超えると継ぎ足し生成になり、曲のまとまりが崩れやすく時間もかかる)
#   prompt   = 英語の説明 ← MusicGen は英語プロンプトの方が精度が高い
#   gain_db  = -6        ← (任意) 音量。会話シーンは小さめに
#   copy_of  = 別の상자  ← (任意) 生成せず別の曲をコピー
#   seed     = 整数      ← (任意) 曲ごとの乱数シード
# 行頭 # はコメント。prompt は次の行をインデントすると複数行で書けます。
# ============================================================
